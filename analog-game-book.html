アプリ・音声・インターネットが使えない時も、スタッフの読み上げだけで7ゲームを進行できます。事前に印刷しておけば完全オフラインで使用できます。

全7ゲーム各3パターン各10問全210問裁判の証拠30件

使い方：遊ぶゲームを一つ選び、パターン1〜3のどれか一セットを選びます。スタッフがルールと第1問から順に読み上げてください。全部行う必要はありません。時間に合わせて途中で終了できます。

用意するもの

  • この全お題集の印刷物
  • 筆記用具と得点表
  • 1分を測れるタイマー
  • ぴったりチャレンジ用の時計・定規など

ジェスチャー対決

二人一組・チーム戦

ルール

一人が言葉や声を使わずに演じ、もう一人が答えます。一チーム2問で、1問ごとに役割を交代します。

得点を付ける場合の例：制限時間内の正解1問につき1点。制限時間は会場で決めます。

スタッフの進め方

  1. 答える人に後ろを向くか耳をふさいでもらう
  2. 演じる人だけに秘密のお題を見せる
  3. 答える人を戻し、スタッフがスタートを合図する
  4. 正解または時間終了で止め、次の役割へ交代する

もしも裁判

個人戦

ルール

お題について有罪か無罪かを選び、理由を説明します。その後に追加の証拠を読み、最終判決と理由を発表します。

正解はありません。得点を付ける場合は、理由の分かりやすさや発想を拍手・投票などで判定します。

スタッフの進め方

  1. 裁判のお題を読む
  2. 挑戦者が最初の判決と理由を発表する
  3. スタッフが追加の証拠を読む
  4. 挑戦者が最終判決と理由を発表する

もしも裁判｜パターン1

  1. 第1問

    共有の冷蔵庫に残っていた最後のプリンを食べた人は、有罪でしょうか、無罪でしょうか。

    追加の証拠

    プリンの下から、『本日中にご自由にどうぞ』と書かれた小さなメモが見つかりました。ただし、誰が書いたかは分かりません。

    大事な日に持ち主を起こさなかった目覚まし時計は、有罪でしょうか、無罪でしょうか。

  4. 第4問

    追加の証拠

ぴったりチャレンジ

個人戦または二人一組のチーム戦

ルール

時間や長さなどを、自分の感覚で目標に近づけます。スタッフが安全確認と計測を行います。

目標との差が最も小さい人またはチームが勝ちです。お題に同点時の条件があれば、それに従います。

スタッフの進め方

  1. 個人戦かチーム戦を決める
  2. 該当するお題だけを読む
  3. スタッフがスタートを合図して計測する
  4. 目標との差を記録する

ぴったりチャレンジ｜パターン1

  1. 第1問

    個人戦

    目を閉じ、10秒たったと思ったら手を挙げてください。

    チーム戦

    相談せずに目を閉じ、二人とも10秒だと思った瞬間に手を挙げてください。二人の平均が10秒に近いチームが勝ちです。同点の場合は、二人の時間差が小さいチームが上です。

  2. 第2問

    個人戦
