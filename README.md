# サイ校 わくわくゲームショー — 音声アバター司会版

ゲームURL: https://saiko-world-grand-prix.pages.dev/
アバター版の別入口: https://saiko-world-grand-prix.pages.dev/avatar.html
スタッフ用カンペ（完全別ページ・A4横印刷）: https://saiko-world-grand-prix.pages.dev/host-cue-sheet.html

## 目的
スタッフが作業で動いていても、アバター「もこ」がゲームの説明、例題、新しいお題、次ゲームへの進行を声で行う。画面の大部分にはアバターと字幕だけを表示。初回だけチーム数とスタッフの呼び名を選び、マイクを許可する。

## 基本進行
1. 2〜10チームを設定、スタッフ名を入力（初期値「吉村」）。
2. 「ゲームを始める」をタップ。マイク利用の許可を確認。
3. もこが第1ゲームの説明と例題を音声で発表。スタッフへ実演を依頼。
4. スタッフが「説明終わったよ」と声で返事。
5. もこが本番用の新しいお題を生成し、声で発表。
6. 「次のお題」「次のゲーム」「もう一度」「もっと簡単に」「新証拠」などの声で進行。
7. 「チーム1に5点」のような声で得点を追加。「順位を教えて」で現在順位を読み上げる。

## アバターと実装
- avatar-stage.js / avatar-stage.css：表情・口の動きを伴うアバター、字幕、音声合成、ブラウザ音声認識、ゲーム進行の状態管理。不要なスタッフ操作画面は表示しない。
- functions/api/partner.js：Cloudflare Workers AI のお題生成／相談機能。制限や障害の場合はルールに合う端末内の予備お題を使用。
- 旧版は /new-game.html と /studio.html に残し、本番画面だけアバター中心に切り替え。
- qa/avatar.test.mjs：音声コマンドから例題、返事、本番、次ゲーム、加点まで自動テスト。
- qa/avatar-live.mjs：Cloudflare上でアバター版の公開ファイルを検証。
- GitHubの saiko-world-grand-prix ブランチのみ修正。mainの名札アプリやBASE WORK HUBは変更しない。

## 重要な制約
- Web Speech API（SpeechRecognition、speechSynthesis）対応ブラウザと端末のマイク・スピーカーが必要。多くのブラウザで開始時に一度のタップとマイク許可が必須。端末やブラウザにより連続音声認識は中断される可能性がある。音声の読み上げ中はアバターが聞き取らない（自己音声の誤認識防止）。
- Windows/Android等のブラウザ・マイクの実機テストは人手で必要。GitHub自動テストだけでは実マイクや実スピーカーまでは検証できない。
- スタッフが端末から離れる場合は、その端末のマイクから声が届くか要確認。必要なら対応マイクを接続する。
- マイクが使えない場合、設定ボタンから文字入力へ切り替えられる。
- 得点は同一端末のブラウザ内に保存。別の端末と自動同期はしない。
- AIへのスタッフ入力と最近のお題はサーバーへ送信するので、個人情報を話さない。
- Cloudflare無料枠での運用を想定し、有料契約や自動課金は増やさない。
