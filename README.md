# サイ校・おバカ世界選手権（かわいいAIゲーム v4）

**司会は人間のスタッフ。** AIの相棒「もこ」は、スタッフと相談しながら本番で使用するゲームの**お題案**を作ります。相談や下書きは観客画面には出ず、スタッフが「このお題で出題！」を選んだときだけ公開します。

公開URL: https://saiko-world-grand-prix.pages.dev/
テスト画面: https://saiko-world-grand-prix.pages.dev/new-game.html
印刷・スタッフ専用カンペ（ゲームと別）: https://saiko-world-grand-prix.pages.dev/host-cue-sheet.html

## 使い方

1. 2〜10チームを選び、名前を入力して開始。既存の大会が保存されている場合は途中から復元。
2. ゲーム種目を選ぶ。
3. 「もことお題相談」で、希望の難易度やテーマを自由に相談。**相談だけでは出題されない**。
4. 「お題案を作る」で非公開のお題案を出してもらう。「この案を直す」でやり取りを繰り返せる。
5. スタッフが納得したら「このお題で出題！」で確定。観客画面には確定したお題と得点だけを表示。
6. 結果に応じてチームへ加点。裁判では検察・弁護・判定役の判決で自動加点。

## システム構成

- index.html / game-v4.js / game-v4.css: 可愛いゲーム画面（ピンク、ミント、ラベンダー、うさぎのもこ）
- functions/api/partner.js: Cloudflare Workers AI による自然言語相談と、お題案の構造化出力（スタッフ向け非公開）
- ゲームは毎回お題を新規生成。AIが使えない場合は固定ルールと組み合わせにより端末内で予備出題。予備出題はAIの会話ではないことを表示。
- manifest.webmanifest / saiko-icon.svg: スマホのホーム画面追加用
- qa/v4.test.mjs / qa/partner.test.mjs: 会話・下書き非公開・確定・採点・2〜10チームの動作テスト
- qa/v4-live.mjs / qa/live-deploy.mjs: 公開したCloudflareへ実際にアクセスして確認

## 注意事項

- 得点・チーム名・AIとの会話履歴は操作したブラウザに保存され、端末間の同期はない。
- AIへ送るスタッフのメッセージや相談履歴には氏名・医療情報などの個人情報を入力しない。
- Cloudflare無料枠での運用を想定。AI利用制限や通信障害では非AIの予備出題に切り替わる。契約や課金を自動追加しない。
- 名札アプリの main ブランチは編集せず、saiko-world-grand-prix ブランチだけで独立運用。
- スタッフ用の準備物一覧・進行マニュアルはゲーム画面へ埋め込まない。必要なら別の紙のカンペを利用する。
