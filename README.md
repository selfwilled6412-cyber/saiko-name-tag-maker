# サイ校ゲーム — 完全音声アバター司会版

本番URL: https://saiko-world-grand-prix.pages.dev/

スタッフ用カンペ: https://saiko-world-grand-prix.pages.dev/host-cue-sheet.html

## 使い方

1. 本番URLをChromeまたはEdgeで開く。
2. アバターを一度タップし、ブラウザのマイク利用を許可する。
3. アバターに聞かれたら「3チーム」のように2〜10のチーム数を声で答える。
4. アバターが第1ゲームのルールと例題を話し、スタッフへ実演を依頼する。
5. 実演後、スタッフが「説明終わったよ」と話す。
6. アバターがWorkers AIで作った本番用の新しいお題を声で発表する。
7. 「次のお題」「次のゲーム」「もう一度」「もっと簡単に」「新しい証拠」などの声で進める。
8. 「チーム1に5点」と話し、アバターの確認に「はい」と答えると加点される。「順位を教えて」で現在順位を聞ける。

通常画面に文字、字幕、ボタン、得点、ゲーム情報は表示しない。アバターと背景だけを表示する。管理・復旧画面は、画面を1.4秒長押しした場合だけ開く。キーボードではShift+Escapeでも開閉できる。

## 実装

- `coach-avatar.png`: ユーザー提供の男性スポーツコーチ写真を参照して作成した、透明背景のイラストアバター。
- `avatar-stage.js`: 音声合成、音声認識の安全な自動再開、2〜10チーム、例題と本番のお題、得点確認、順位、状態保存、長押し管理画面。
- `avatar-stage.css`: アバターだけを見せるレスポンシブ画面。発話中と聞き取り中は文字ではなく光の輪で状態を表現する。
- `functions/api/partner.js`: Cloudflare Workers AIの`@cf/qwen/qwen3-30b-a3b-fp8`で、新規お題と短い会話を生成する。AIが使えない場合は端末内の予備お題に自動で切り替わる。
- `qa/avatar.test.mjs`: 音声だけの進行、得点の確認、再開、長押し管理画面を自動検証する。

## ブラウザ上の制約

- ブラウザの仕様により、初回だけユーザーのタップとマイク許可が必要。ページを再読み込みした場合も、音声を再開するため一度タップする。
- Web Speech APIに対応したChromeまたはEdgeを推奨。iPhone/iPadを含め、ブラウザやOSの組み合わせによって音声認識が途中で止まる場合があるため、終了後に自動再開する。
- アバターの読み上げ中は認識を停止し、読み上げ終了後に待ち時間を置いてから再開する。これにより自己音声の誤認識を減らす。
- 得点は誤認識防止のため、「はい」と確認されるまで反映しない。「今の得点を取り消して」で直前の加点を戻せる。
- 騒音、スタッフとマイクの距離、端末スピーカーの音量により精度は変わる。必要なら外付けマイクを使う。
- 得点と進行は同じ端末のブラウザに保存され、端末間では同期しない。
- スタッフの発話と最近のお題は、新しいお題を作る場合にCloudflare Workers AIへ送られる。個人情報は話さない。
- Workers AIの無料割当を優先し、外部の有料AI APIやAPIキーは使わない。無料割当超過や一時障害時は予備お題を使う。
