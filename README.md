# サイ校・おバカ世界選手権

施設内で大人が本気で笑って競う、チーム対抗2時間のゲームショー司会アプリ。

## 使い方

1. `index.html` をスマホまたはPCのブラウザで開く（サーバー・契約不要）。
2. 3チームの名前を変更する。
3. 上部の競技タブ順に進める。お題は「次のお題」で切り替えられる。
4. 各競技後に順位を選んで「得点を確定」。特別裁判は各事件の判決を決めてから登録。
5. 最後の表彰式で優勝チームを発表。

### 資材

A4コピー用紙 約30枚、ペン、紙コップ3個、スマホ／PC、机・椅子。オプションで定規。

### 得点

通常種目の順位は5 / 3 / 1点。最終投球は10 / 6 / 2点。裁判は各事件で勝訴3、敗訴1、裁判官2点。自動保存され、再読み込み後も残る。必要なときだけ右上の「リセット」を選ぶ。

### 運用・注意

- お題と判定はアプリ内に含まれるので通信不要。効果音はブラウザの許可や端末設定で無音になる場合がある。
- データは**端末ごと**のブラウザ保存（localStorage）。別端末で自動同期されない。
- 出題者だけお題画面を見せるなど、競技ごとに表示方法を調整する。
- このアプリはリアルタイムの多人同時入力アプリではなく、1台の司会用端末を想定。
- 競技に参加できない動作や会話は強要しない。指差し・筆談・代読・着席参加OK。
- 著作権のあるテレビ番組の映像・ロゴ・効果音は使用していない。

### GitHub（ゲーム専用ブランチ）

`selfwilled6412-cyber/saiko-name-tag-maker` の `saiko-world-grand-prix` ブランチにゲーム本体を保存。`main` は名札アプリのまま変更しない。ゲーム専用のCloudflare Pagesを作る場合はこのブランチを指定し、出力フォルダーはルートのまま、ビルドコマンドは不要。

### Cloudflare Pagesで公開

静的な `index.html` だけで動きます。無料枠のCloudflare Pagesにこのフォルダーをアップロードするか、GitHubリポジトリに置いてPagesのGit連携を設定できます。無料枠の利用条件はCloudflare側で確認してください。特定のCloudflareアカウントにはまだ自動公開していません。
